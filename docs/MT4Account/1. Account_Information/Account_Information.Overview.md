# MT4Account — Account Information — Overview

> Account snapshot plus performance: balance/equity/margin, trade statistics, equity curve and unrealized-P/L extrema.

## 📁 What lives here

* **[Account Summary](account_summary.md)** — Complete account snapshot (balance, equity, margin, leverage, currency, server time) in a single call. **(RECOMMENDED)**
* **[Trade Statistics](trade_stats.md)** — Aggregated trade statistics — profit factor, drawdowns, per-market breakdown, win/loss metrics.
* **[Unrealized P/L Extrema](trade_unrealized_pl.md)** — Per-open-order unrealized P/L extrema (best/worst floating P/L with timestamps).
* **[Equity Curve](equity_history.md)** — Time series of equity/balance points with running drawdowns — the equity curve.
* **[Stats + Equity + Trades](trade_stats_equity_history.md)** — Combined statistics, equity-chart points and the trade list in a single call.
