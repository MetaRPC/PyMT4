# MT4Service — Streaming Methods

> The same real-time streams as [MT4Account](../MT4Account/5.%20Streaming_Methods/Streaming_Methods.Overview.md), exposed on the facade.

All are async generators — consume with `async for`, and always drive them so they can be
stopped cleanly (cancel the consuming task). See [gRPC Stream Management](../All_Guides/GRPC_STREAM_MANAGEMENT.md).

---

## `on_symbol_tick(symbols)`

```python
async def on_symbol_tick(symbols: str | Iterable[str])
```

Live bid/ask ticks. Accepts a single symbol **or** an iterable of symbols.

```python
async for td in service.on_symbol_tick(["EURUSD", "GBPUSD"]):
    t = td.symbol_tick
    print(t.symbol, t.bid, t.ask)
```

> **Underlying:** [`MT4Account.on_symbol_tick`](../MT4Account/5.%20Streaming_Methods/on_symbol_tick.md).

---

## `on_trade()`

```python
async def on_trade()
```

Trade events — new / updated / removed orders.

```python
async for ev in service.on_trade():
    for o in ev.event_data.new_orders:
        print("NEW", o.ticket, o.symbol)
```

> **Underlying:** [`on_trade`](../MT4Account/5.%20Streaming_Methods/on_trade.md) — event structure and `SUB_OP_*` enums.

---

## `on_opened_orders_tickets(pull_interval_milliseconds=None)`

```python
async def on_opened_orders_tickets(pull_interval_milliseconds: int | None = None)
```

Periodic snapshots of open position / pending ticket lists.

```python
async for ev in service.on_opened_orders_tickets(pull_interval_milliseconds=1000):
    print(list(ev.position_tickets), list(ev.pending_order_tickets))
```

> **Underlying:** [`on_opened_orders_tickets`](../MT4Account/5.%20Streaming_Methods/on_opened_orders_tickets.md).

---

## `on_opened_orders_profit(timer_period_milliseconds=None)`

```python
async def on_opened_orders_profit(timer_period_milliseconds: int | None = None)
```

Live P/L of open orders on a timer.

```python
async for ev in service.on_opened_orders_profit(timer_period_milliseconds=1000):
    for o in ev.opened_orders_with_profit_updated:
        print(o.ticket, o.order_profit)
```

> **Underlying:** [`on_opened_orders_profit`](../MT4Account/5.%20Streaming_Methods/on_opened_orders_profit.md) — `MT4_SUB_ENUM_EVENT_GROUP_TYPE` / `SUB_OP_*` enums.

---

## `on_connect_state(terminal_ids=None)`

```python
async def on_connect_state(terminal_ids: Sequence[str] | None = None)
```

Terminal connection-state changes (connected/alive flags, server, account, timestamp).

```python
async for ev in service.on_connect_state():
    print(ev.state, ev.is_connected, ev.server)
    break
```

> **Underlying:** [`on_connect_state`](../MT4Account/5.%20Streaming_Methods/on_connect_state.md).
