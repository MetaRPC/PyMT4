# MT4Service — Symbols & Quotes

> Symbols, quotes and bar history — with **masks**, **string timeframes** and **unpacked lists**.

This is where the facade adds the most convenience over
[MT4Account](../MT4Account/3.%20Symbols_Quotes/Symbols_Quotes.Overview.md): it unpacks protobuf
containers into plain Python lists, filters by mask, accepts a string `timeframe="H1"`, and
auto-computes a history window from `limit`.

---

## `symbols(mask=None)`

```python
async def symbols(mask: str | Sequence[str] | None = None) -> list
```

Returns the symbol list **as a Python list** (not a protobuf container). `mask`:

* `None` → all symbols,
* `str` → case-insensitive **substring** filter (e.g. `"usd"`),
* `list/tuple` → keep only those **exact** names (case-insensitive).

```python
all_syms = await service.symbols()
usd      = await service.symbols("usd")             # substring
majors   = await service.symbols(["EURUSD", "GBPUSD"])
print(len(all_syms), len(usd), len(majors))
```

> **Underlying:** [`MT4Account.symbols`](../MT4Account/3.%20Symbols_Quotes/symbols.md) (raw `SymbolNameInfos`).

## `quote(symbol)` · `quote_many(symbols)`

```python
async def quote(symbol: str) -> QuoteData
async def quote_many(symbols: Sequence[str]) -> QuoteManyData
```

Pass-throughs. `quote` returns one `QuoteData` (`bid`/`ask`/`high`/`low`/`date_time`);
`quote_many` returns `QuoteManyData` with `quotes`.

```python
q = await service.quote("EURUSD")
print(q.bid, q.ask)

data = await service.quote_many(["EURUSD", "GBPUSD"])
for qq in data.quotes:
    print(qq.symbol, qq.bid, qq.ask)
```

> **Underlying:** [`quote`](../MT4Account/3.%20Symbols_Quotes/quote.md) · [`quote_many`](../MT4Account/3.%20Symbols_Quotes/quote_many.md).

## `quote_history(symbol, timeframe="H1", since=None, until=None, limit=100)`

```python
async def quote_history(
    symbol: str, *, timeframe: str | int = "H1",
    since: datetime | None = None, until: datetime | None = None,
    limit: int | None = 100,
) -> QuoteHistoryData
```

OHLC bars with a **string timeframe** (`"M1"`, `"M5"`, `"M15"`, `"M30"`, `"H1"`, `"H4"`, `"D1"`, `"W1"`, `"MN1"`). If you don't pass `since`/`until`, the service computes a window from `timeframe` × `limit` ending now.

**Returns:** `QuoteHistoryData` with `historical_quotes` — see the [bar fields](../MT4Account/3.%20Symbols_Quotes/quote_history.md).

```python
# last ~100 H1 bars, no dates needed
data = await service.quote_history("EURUSD", timeframe="H1", limit=100)
for b in data.historical_quotes[-3:]:
    print(b.time.ToDatetime(), b.open, b.high, b.low, b.close)
```

> **Underlying:** [`MT4Account.quote_history`](../MT4Account/3.%20Symbols_Quotes/quote_history.md) (takes the `ENUM_QUOTE_HISTORY_TIMEFRAME` enum directly).

## `symbol_params_many(symbols)`

```python
async def symbol_params_many(symbols: str | Sequence[str] | None) -> list | SymbolParamsManyData
```

Per-symbol trading parameters. `str` → one symbol; `None` → all (as a list); `list` → all,
filtered to those names.

```python
info = (await service.symbol_params_many("EURUSD"))      # one symbol's params
one  = info.symbol_infos[0] if hasattr(info, "symbol_infos") else info[0]
print(one.Digits, one.VolumeMin, one.VolumeStep)
```

> **Underlying:** [`MT4Account.symbol_params_many`](../MT4Account/3.%20Symbols_Quotes/symbol_params_many.md) — the full ~75-field spec and SP enums.

## `tick_value_with_size(symbol=None, symbols=None)`

```python
async def tick_value_with_size(symbol: str | None = None, *, symbols: Sequence[str] | None = None) -> TickValueWithSizeData
```

Accepts a single `symbol` or a list of `symbols` (defaults to `"EURUSD"` if neither given).

**Returns:** `TickValueWithSizeData` with `infos` (`symbolName`, `TradeTickValue`, `TradeTickSize`, `TradeContractSize`).

```python
d = await service.tick_value_with_size(symbols=["EURUSD", "XAUUSD"])
for i in d.infos:
    print(i.symbolName, i.TradeTickValue)
```

> **Underlying:** [`MT4Account.tick_value_with_size`](../MT4Account/3.%20Symbols_Quotes/tick_value_with_size.md).

## `symbol_select(symbol, select=True)`

```python
async def symbol_select(symbol: str, select: bool = True) -> SymbolSelectData
```

Add a symbol to (or remove it from) Market Watch. Pass-through.

**Returns:** `SymbolSelectData` with `success`.

```python
res = await service.symbol_select("XAUUSD", True)
print("selected:", res.success)
```

> **Underlying:** [`MT4Account.symbol_select`](../MT4Account/3.%20Symbols_Quotes/symbol_select.md).

## `server_timezone()`

```python
async def server_timezone() -> ServerTimezoneData
```

Trade-server timezone / UTC offset. Pass-through.

**Returns:** `ServerTimezoneData` with `server`, `utc_offset_seconds`, `source`.

```python
tz = await service.server_timezone()
print(f"{tz.server}: UTC offset {tz.utc_offset_seconds}s")
```

> **Underlying:** [`MT4Account.server_timezone`](../MT4Account/3.%20Symbols_Quotes/server_timezone.md).
