# MT4Service — Account Information

> Account state through the mid-level facade.

Account snapshot plus the performance/history family (statistics, equity curve, unrealized-P/L extrema). Each is a thin pass-through to the matching [`MT4Account`](../MT4Account/1.%20Account_Information/Account_Information.Overview.md) method; the stats methods take a friendly `since=` datetime instead of the raw `from_time`.

---

## `account_summary()`

```python
async def account_summary() -> AccountSummaryData
```

Returns the full account snapshot — balance, equity, margin, leverage, currency, trade mode, server time. Identical payload to the low-level call.

**Returns:** `AccountSummaryData` (see the [field table & enums](../MT4Account/1.%20Account_Information/account_summary.md)).

```python
s = await service.account_summary()
floating = s.account_equity - s.account_balance
print(f"Balance {s.account_balance:.2f} {s.account_currency} | floating {floating:+.2f}")
```

> **Underlying:** [`MT4Account.account_summary`](../MT4Account/1.%20Account_Information/account_summary.md) — full signature, proto, fields, enums and more examples.

---

## `trade_stats(since=None)`

```python
async def trade_stats(since: datetime | None = None) -> StatsData
```

Aggregated statistics — profit factor, win/loss, drawdowns, per-market breakdown. `since` scopes the window (omit for full history).

```python
st = await service.trade_stats()
print(f"PF={st.profit_factor:.2f} trades={st.trades} growth={st.growth_percent:+.2f}%")
```

> **Underlying:** [`MT4Account.trade_stats`](../MT4Account/1.%20Account_Information/trade_stats.md) — `StatsData` fields and nested messages.

## `trade_unrealized_pl(since=None)`

```python
async def trade_unrealized_pl(since: datetime | None = None) -> TradeUnrealizedPLData
```

Per-open-order MFE/MAE excursions (`extrema`).

```python
upl = await service.trade_unrealized_pl()
print("extrema entries:", len(upl.extrema))
```

> **Underlying:** [`MT4Account.trade_unrealized_pl`](../MT4Account/1.%20Account_Information/trade_unrealized_pl.md).

## `equity_history(since=None, exclude_same_bars=None)`

```python
async def equity_history(since: datetime | None = None, exclude_same_bars: bool | None = None) -> EquityHistoryData
```

The equity curve (`points`). Pass `exclude_same_bars=True` to shrink the payload.

```python
eq = await service.equity_history(exclude_same_bars=True)
print("equity points:", len(eq.points))
```

> **Underlying:** [`MT4Account.equity_history`](../MT4Account/1.%20Account_Information/equity_history.md).

## `trade_stats_equity_history(since=None, exclude_same_bars=None)`

```python
async def trade_stats_equity_history(since: datetime | None = None, exclude_same_bars: bool | None = None) -> StatsWithChartsData
```

Stats + equity curve + trades in one call (`stats`, `charts`, `trades`, `open_trades`).

```python
r = await service.trade_stats_equity_history(exclude_same_bars=True)
print(f"charts={len(r.charts)} trades={len(r.trades)} open={len(r.open_trades)}")
```

> **Underlying:** [`MT4Account.trade_stats_equity_history`](../MT4Account/1.%20Account_Information/trade_stats_equity_history.md).
