# MT4Service — Orders & History

> Open orders and closed history, with **string sort modes** and **datetime windows** instead of protobuf enums.

What the facade adds over [MT4Account](../MT4Account/2.%20Orders_History/Orders_History.Overview.md): you pass `sort="open_desc"` and `since=/until=` datetimes; the service maps them to the right enum and request fields.

---

## `opened_orders(sort=None)`

```python
async def opened_orders(*, sort: str | int | None = None) -> OpenedOrdersData
```

All currently open orders (market + pending). `sort` is a friendly value mapped to
`EnumOpenedOrderSortType` (e.g. `"open_asc"`, `"open_desc"`, `"ticket_asc"`, `"ticket_desc"`); omit for the default.

**Returns:** `OpenedOrdersData` with `order_infos` — see the [field table](../MT4Account/2.%20Orders_History/opened_orders.md).

```python
data = await service.opened_orders(sort="open_desc")
for o in data.order_infos:
    print(o.ticket, o.symbol, o.lots, f"{o.profit:+.2f}")
```

> **Underlying:** [`MT4Account.opened_orders`](../MT4Account/2.%20Orders_History/opened_orders.md).

---

## `opened_orders_tickets()`

```python
async def opened_orders_tickets() -> OpenedOrdersTicketsData
```

Just the open ticket numbers (lightweight). Pass-through.

**Returns:** `OpenedOrdersTicketsData` with `tickets` (`list[int]`).

```python
t = await service.opened_orders_tickets()
print(list(t.tickets))
```

> **Underlying:** [`MT4Account.opened_orders_tickets`](../MT4Account/2.%20Orders_History/opened_orders_tickets.md).

## `orders_history(sort=None, since=None, until=None, page=None, page_size=None)`

```python
async def orders_history(
    *, sort: str | int | None = None,
    since: datetime | None = None, until: datetime | None = None,
    page: int | None = None, page_size: int | None = None,
) -> OrdersHistoryData
```

Closed orders over a window. The service maps `sort → EnumOrderHistorySortType`,
`since/until → from_time/to_time`, and `page/page_size → page_number/items_per_page`.

**Returns:** `OrdersHistoryData` with `orders_info`, `total_count`, `next_page_token` — see the [field table](../MT4Account/2.%20Orders_History/orders_history.md).

```python
from datetime import datetime, timedelta
end = datetime.utcnow()
hist = await service.orders_history(sort="close_desc", since=end - timedelta(days=30), until=end)
print(f"{hist.total_count} closed orders")
```

> **Underlying:** [`MT4Account.orders_history`](../MT4Account/2.%20Orders_History/orders_history.md) — sort enum values and more examples.
