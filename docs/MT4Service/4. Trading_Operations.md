# MT4Service — Trading Operations

> Order operations with **friendly keyword names**, plus the high-level `MT4ServiceTrade` helpers.

Two levels here:

* **Facade methods on `MT4Service`** — the same four operations as [MT4Account](../MT4Account/4.%20Trading_Operations/Trading_Operations.Overview.md), but accepting friendly keys (`side`, `lots`, `sl`, `tp`, `magic`, `deviation_pips`).
* **`MT4ServiceTrade` helpers** — one-call `buy_market` / `sell_limit` / `close` / … built on the facade.

All of these ultimately call [`MT4Account.order_send`](../MT4Account/4.%20Trading_Operations/order_send.md) & friends, so failures raise `ApiExceptionMT4` — see the [Return Codes Reference](../All_Guides/RETURN_CODES_REFERENCE.md).

---

## Facade methods (`MT4Service`)

### `order_send(**kwargs)`

```python
async def order_send(**kwargs) -> OrderSendData
```

Friendly wrapper over the raw call. Accepted keys:

| Friendly key | Maps to | Notes |
|--------------|---------|-------|
| `symbol` | `symbol` | required |
| `side="buy"/"sell"` **or** `type="buy_limit"/…` **or** `operation_type=` | `operation_type` | one of these picks the `OrderSendOperationType` |
| `lots` **or** `volume` | `volume` | required |
| `price` | `price` | required for pending orders |
| `sl` | `stoploss` | SL price |
| `tp` | `takeprofit` | TP price |
| `magic` | `magic_number` | |
| `deviation_pips` | `slippage` | |
| `comment` | `comment` | |

**Returns:** `OrderSendData` (`ticket`, `volume`, `price`, `open_time`).

```python
res = await service.order_send(symbol="EURUSD", side="buy", lots=0.01,
                               sl=1.0950, tp=1.1050, magic=777)
print("ticket", res.ticket)
```

> **Underlying:** [`MT4Account.order_send`](../MT4Account/4.%20Trading_Operations/order_send.md) — the `OC_OP_*` enum and raw fields.

### `order_modify(ticket, **kwargs)`

```python
async def order_modify(ticket: int, **kwargs) -> OrderModifyData
```

Accepts `sl_price → new_stop_loss`, `tp_price → new_take_profit` (plus `new_price`, `new_expiration`).

```python
await service.order_modify(ticket, sl_price=1.0960, tp_price=1.1040)
```

> **Underlying:** [`order_modify`](../MT4Account/4.%20Trading_Operations/order_modify.md).

### `order_close_delete(ticket, **kwargs)` · `order_close_by(ticket_a, ticket_b)`

```python
async def order_close_delete(ticket: int, **kwargs) -> OrderCloseDeleteData
async def order_close_by(ticket_a: int, ticket_b: int) -> OrderCloseByData
```

Close a market order / delete a pending (`lots=`, `closing_price=`, `slippage=` pass through), or net two opposite tickets.

```python
await service.order_close_delete(ticket)              # full close / delete
await service.order_close_delete(ticket, lots=0.01)   # partial
await service.order_close_by(ticket_a, ticket_b)      # net a hedge
```

> **Underlying:** [`order_close_delete`](../MT4Account/4.%20Trading_Operations/order_close_delete.md) · [`order_close_by`](../MT4Account/4.%20Trading_Operations/order_close_by.md).

## Trade helpers (`MT4ServiceTrade`)

Build the helper from a service, optionally set shared defaults, then use one-call entries:

```python
from app.MT4Service import MT4Service, MT4ServiceTrade

trade = MT4ServiceTrade(service)
trade.set_trade_defaults(magic=777, deviation_pips=3, comment="my bot")
```

### `set_trade_defaults(magic=None, deviation_pips=None, comment=None)`

Sets defaults applied by `order_send_with_defaults` and the helpers below.

### `order_send_with_defaults(**kwargs)`

Like `service.order_send`, but fills in the defaults set above.

### Market & pending helpers

```python
async def buy_market(symbol, lots, sl=None, tp=None, magic=None, deviation_pips=None, comment=None) -> int
async def sell_market(symbol, lots, sl=None, tp=None, magic=None, deviation_pips=None, comment=None) -> int
async def buy_limit(symbol, price, lots, sl=None, tp=None, magic=None, comment=None) -> int
async def sell_limit(symbol, price, lots, sl=None, tp=None, magic=None, comment=None) -> int
async def buy_stop(symbol, price, lots, sl=None, tp=None, magic=None, comment=None) -> int
async def sell_stop(symbol, price, lots, sl=None, tp=None, magic=None, comment=None) -> int
```

Each opens the corresponding order and returns the **ticket**. `sl`/`tp` are absolute prices.

```python
ticket = await trade.buy_market("EURUSD", lots=0.01, sl=1.0950, tp=1.1050)
pend   = await trade.buy_limit("EURUSD", price=1.0900, lots=0.01)
```

### Manage

```python
async def modify_sl_tp(ticket, sl_price=None, tp_price=None)
async def close(ticket)
async def close_partial(ticket, lots)
async def close_by(ticket_a, ticket_b)
```

```python
await trade.modify_sl_tp(ticket, sl_price=1.0960, tp_price=1.1040)
await trade.close_partial(ticket, lots=0.01)
await trade.close(ticket)
```

> **Even higher level?** [`MT4Sugar`](../MT4Sugar/MT4Sugar.Master.Overview.md) (`service.sugar`) adds pip-based SL/TP, lot sizing by risk, trailing stops and `close_all`.
