# MT4Sugar — Risk Sizing

> Turn a risk budget into a lot size, and reason about per-trade risk.

---

## `calc_lot_by_risk(symbol, risk_percent, stop_pips, balance=None)`

```python
async def calc_lot_by_risk(symbol: str, risk_percent: float, stop_pips: float, balance: float | None = None) -> float
```

The headline sizing helper: returns the **lot size** so that hitting a `stop_pips` stop loses `risk_percent` of the account (balance is read automatically unless you pass one). The result is normalized to the broker's volume step.

```python
lots = await sugar.calc_lot_by_risk("EURUSD", risk_percent=1.0, stop_pips=50)
ticket = await sugar.buy_market("EURUSD", lots=lots, sl_pips=50, tp_pips=100)
```

---

## `calc_cash_risk(symbol, lots, stop_pips)`

```python
async def calc_cash_risk(symbol: str, lots: float, stop_pips: float) -> float
```

The inverse view: the **monetary risk** of a given lot size with a `stop_pips` stop.

```python
risk = await sugar.calc_cash_risk("EURUSD", lots=0.10, stop_pips=30)
print(f"risking {risk:.2f} on this trade")
```

---

## `breakeven_price(entry_price, commission=0.0, swap=0.0)`

```python
def breakeven_price(entry_price: float, commission: float = 0.0, swap: float = 0.0) -> float
```

A **synchronous** helper (no `await`): the price at which a position breaks even after commission and swap.

```python
bp = sugar.breakeven_price(entry_price=1.10000, commission=-2.0, swap=-0.5)
```

> To move a live order's stop to breakeven, use [`auto_breakeven` / `close_by_breakeven`](./7.%20Trailing_Breakeven.md).
