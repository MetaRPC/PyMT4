# MT4Sugar — Watchers & Waiters

> Callback-based background watchers, and `await`-able waiters for order lifecycle events.

**Watchers** register a callback and return a **subscription id** (stop them with `unwatch`).
**Waiters** block until something happens (or a timeout).

---

## Watchers (callback + subscription id)

```python
async def watch_ticks(symbol: str, on_tick, throttle_ms: int | None = None) -> str
async def watch_trades(on_event) -> str
async def watch_opened_orders(on_event) -> str
async def watch_profit(on_event, timer_period_ms: int = 1000) -> str
async def watch_tickets(on_event, pull_interval_ms: int = 500) -> str
async def unwatch(subscription_id: str)
```

Unlike the low-level `async for` streams, watchers hand each event to your **callback** and
run in the background — your code keeps going.

```python
def on_tick(t):
    print(t)

sub = await sugar.watch_ticks("EURUSD", on_tick, throttle_ms=200)
# ... later ...
await sugar.unwatch(sub)
```

```python
# live P/L callback
pid = await sugar.watch_profit(lambda ev: print("floating:", ev), timer_period_ms=1000)
# trade events
tid = await sugar.watch_trades(lambda ev: print("trade:", ev))
```

| Watcher | Fires on |
|---------|----------|
| `watch_ticks(symbol, on_tick)` | each tick (optionally throttled) |
| `watch_trades(on_event)` | trade events (open/modify/close) |
| `watch_opened_orders(on_event)` | changes to the open-order set |
| `watch_profit(on_event, timer_period_ms)` | periodic open-order P/L |
| `watch_tickets(on_event, pull_interval_ms)` | periodic ticket-list snapshots |

---

## Waiters (`await` until an event)

```python
async def wait_filled(ticket: int, timeout_s: float | None = None) -> bool
async def wait_closed(ticket: int, timeout_s: float | None = None) -> bool
```

Block until a pending order fills, or an order closes.

```python
ticket = await sugar.buy_limit("EURUSD", price=1.0900, lots=0.01)
if await sugar.wait_filled(ticket, timeout_s=300):
    print("filled!")
    await sugar.wait_closed(ticket)   # then wait for it to close
```

> See also [`wait_price`](./2.%20Prices_Quotes.md) to wait on a price level.
