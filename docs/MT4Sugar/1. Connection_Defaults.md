# MT4Sugar — Connection & Defaults

> Session helpers and shared defaults that the rest of the Sugar API reuses.

---

## `ensure_connected()`

```python
async def ensure_connected()
```

Make sure the underlying session is live (reconnect if needed). Call at the start of a routine; most Sugar methods also guard themselves.

```python
await sugar.ensure_connected()
```

## `ping()`

```python
async def ping()
```

Lightweight liveness check against the terminal.

```python
await sugar.ping()
```

## `ensure_symbol(symbol, preload_params=True, require_trade_allowed=False, force_refresh=False)`

```python
async def ensure_symbol(symbol, preload_params=True, require_trade_allowed=False, force_refresh=False)
```

Make a symbol ready to use — selects it in Market Watch and (by default) preloads its parameters. Pass `require_trade_allowed=True` to also assert trading is enabled.

```python
await sugar.ensure_symbol("XAUUSD", require_trade_allowed=True)
```

---

## `set_defaults(symbol=None, magic=None, deviation_pips=None, slippage_pips=None, risk_percent=None)`

```python
def set_defaults(symbol=None, magic=None, deviation_pips=None, slippage_pips=None, risk_percent=None)
```

Set defaults reused across calls — e.g. a default `symbol`, `magic` tag and `risk_percent`. Order entry and risk sizing fall back to these when you omit the argument.

```python
sugar.set_defaults(symbol="EURUSD", magic=777, deviation_pips=3, risk_percent=1.0)
ticket = await sugar.buy_market(lots=0.01)        # uses default symbol & magic
```

## `with_defaults(**overrides)`

```python
def with_defaults(**overrides)   # context manager
```

Temporarily override defaults for a block, restoring them afterwards.

```python
with sugar.with_defaults(magic=999, deviation_pips=5):
    await sugar.buy_market("EURUSD", lots=0.01)   # magic=999 only here
```

## `get_default(key, fallback=None)`

```python
def get_default(key, fallback=None) -> Any
```

Read a current default value.

```python
print(sugar.get_default("symbol"), sugar.get_default("risk_percent", 1.0))
```

---

## `diag_snapshot()`

```python
async def diag_snapshot() -> dict
```

A diagnostics snapshot (connection state, defaults, active watchers) — handy for logging/health checks.

```python
print(await sugar.diag_snapshot())
```

## `disconnect(delete=False)`

```python
async def disconnect(delete=False)
```

Release the session (optionally deleting the terminal instance). In scripts, prefer `async with MT4Sugar(service)` which cleans up for you.

```python
await sugar.disconnect()
```
