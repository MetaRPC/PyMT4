# MT4Sugar — Order Management

> Modify, close and clean up orders — individually or in bulk.

---

## Modify SL/TP

```python
async def modify_sl_tp_by_pips(ticket: int, sl_pips=None, tp_pips=None)
async def modify_sl_tp_by_price(ticket: int, sl_price=None, tp_price=None)
```

Set SL/TP by **pip distance from entry** or by **absolute price**. Pass only what you want to change.

```python
await sugar.modify_sl_tp_by_pips(ticket, sl_pips=20, tp_pips=40)
await sugar.modify_sl_tp_by_price(ticket, sl_price=1.0950, tp_price=1.1050)
```

---

## Close one order

```python
async def close(ticket: int)
async def close_partial(ticket: int, lots: float)
async def close_by(ticket_a: int, ticket_b: int)
async def close_by_tickets(ticket_a: int, ticket_b: int)
```

`close` closes a market order or deletes a pending; `close_partial` closes part of a
position; `close_by` / `close_by_tickets` net two opposite orders against each other.

```python
await sugar.close(ticket)
await sugar.close_partial(ticket, lots=0.01)
await sugar.close_by(buy_ticket, sell_ticket)
```

---

## Bulk operations

```python
async def close_all(symbol=None, magic=None, only_profit=None)
async def cancel_pendings(symbol=None, magic=None)
```

`close_all` closes open positions (optionally filtered by `symbol` / `magic`, or only the
profitable ones); `cancel_pendings` removes pending orders.

```python
await sugar.close_all()                      # flatten everything
await sugar.close_all(symbol="EURUSD")        # only this symbol
await sugar.close_all(only_profit=True)       # take profits, leave losers
await sugar.cancel_pendings(magic=777)        # drop this bot's pendings
```
