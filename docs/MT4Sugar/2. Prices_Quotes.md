# MT4Sugar — Prices & Quotes

> Quick price reads and history, returned as plain Python values.

---

## `last_quote(symbol)`

```python
async def last_quote(symbol: str) -> dict
```

Latest bid/ask/time as a dict.

```python
q = await sugar.last_quote("EURUSD")
print(q["bid"], q["ask"], q["time"])
```

## `mid_price(symbol)`

```python
async def mid_price(symbol: str) -> float
```

The mid price `(bid + ask) / 2`.

```python
mid = await sugar.mid_price("EURUSD")
```

## `spread_pips(symbol)`

```python
async def spread_pips(symbol: str) -> float
```

Current spread expressed in **pips** (already converted from price units).

```python
if await sugar.spread_pips("EURUSD") <= 2.0:
    await sugar.buy_market("EURUSD", lots=0.01)
```

## `quotes(symbols)`

```python
async def quotes(symbols: list[str]) -> dict
```

Quotes for several symbols at once (keyed by symbol).

```python
data = await sugar.quotes(["EURUSD", "GBPUSD", "USDJPY"])
```

---

## `bars(symbol, timeframe, count=None, since=None, until=None)`

```python
async def bars(symbol: str, timeframe: str, count=None, since=None, until=None) -> list
```

OHLC bars for a **string** timeframe (`"M1"`, `"M5"`, `"H1"`, `"D1"`, …). Give a `count` for the most recent N bars, or a `since`/`until` window.

```python
bars = await sugar.bars("EURUSD", "H1", count=100)
closes = [b["close"] if isinstance(b, dict) else b.close for b in bars]
```

## `ticks(symbol, since=None, until=None, limit=None)`

```python
async def ticks(symbol: str, since=None, until=None, limit=None) -> list
```

Historical ticks for a symbol over a window (or the last `limit`).

```python
t = await sugar.ticks("EURUSD", limit=200)
```

---

## `wait_price(symbol, target, direction=">=", timeout_s=None)`

```python
async def wait_price(symbol: str, target: float, direction: str = ">=", timeout_s: float | None = None) -> bool
```

Block until the price reaches `target` (`direction` is `">="` or `"<="`), or the timeout elapses.

```python
hit = await sugar.wait_price("EURUSD", 1.1050, direction=">=", timeout_s=60)
if hit:
    await sugar.buy_market("EURUSD", lots=0.01)
```
