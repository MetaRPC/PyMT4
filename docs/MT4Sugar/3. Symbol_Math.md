# MT4Sugar — Symbol Math & Normalization

> Pip/point conversions and broker-compliant rounding — the helpers that make pips-first trading work.

---

## `point(symbol)` · `digits(symbol)` · `pip_size(symbol)`

```python
async def point(symbol: str) -> float     # smallest price step (e.g. 0.00001)
async def digits(symbol: str) -> int      # price decimals (e.g. 5)
async def pip_size(symbol: str) -> float  # one pip in price (e.g. 0.0001)
```

```python
print(await sugar.point("EURUSD"), await sugar.digits("EURUSD"), await sugar.pip_size("EURUSD"))
```

---

## `pips_to_price(symbol, pips)` · `price_to_pips(symbol, price_delta)`

```python
async def pips_to_price(symbol: str, pips: float) -> float
async def price_to_pips(symbol: str, price_delta: float) -> float
```

Convert a pip distance to an absolute price delta and back.

```python
delta = await sugar.pips_to_price("EURUSD", 20)      # 20 pips -> 0.0020
pips  = await sugar.price_to_pips("EURUSD", 0.0020)  # 0.0020  -> 20
```

---

## `normalize_price(symbol, price)` · `normalize_lot(symbol, lots)`

```python
async def normalize_price(symbol: str, price: float) -> float
async def normalize_lot(symbol: str, lots: float) -> float
```

Round a price to the symbol's digits, and a lot size into `[VolumeMin, VolumeMax]` on the broker's `VolumeStep`.

```python
p = await sugar.normalize_price("EURUSD", 1.098765)   # -> 1.09877
l = await sugar.normalize_lot("EURUSD", 0.0234)        # -> 0.02
```

> Order-entry methods normalize for you — use these when doing your own math.

---

## `tick_value(symbol, lots=1.0)`

```python
async def tick_value(symbol: str, lots: float = 1.0) -> float
```

Money value of one tick for the given lot size (in the deposit currency).

```python
tv = await sugar.tick_value("EURUSD", lots=0.10)
```
