# MT4Sugar — Trailing & Breakeven

> Automated stop management — trailing stops and move-to-breakeven, run as background workers.

---

## `set_trailing_stop(ticket, distance_pips, step_pips=None)`

```python
async def set_trailing_stop(ticket: int, distance_pips: float, step_pips: float | None = None) -> str
```

Start a background trailing stop that keeps SL ~`distance_pips` behind price, moving it in
`step_pips` increments. **Returns a subscription id** — keep it to stop the trailer later.

```python
sub = await sugar.set_trailing_stop(ticket, distance_pips=20, step_pips=5)
# ... later ...
await sugar.unset_trailing_stop(sub)
```

## `unset_trailing_stop(subscription_id)`

```python
async def unset_trailing_stop(subscription_id: str)
```

Stop a trailing worker started by `set_trailing_stop`.

---

## `auto_breakeven(ticket, trigger_pips, plus_pips=0.0)`

```python
async def auto_breakeven(ticket: int, trigger_pips: float, plus_pips: float = 0.0) -> str
```

Start a worker that moves SL to breakeven (plus `plus_pips`) once the order is `trigger_pips`
in profit. **Returns a subscription id** (stop it with [`unset_trailing_stop`](#unset_trailing_stopsubscription_id) / `unwatch`).

```python
sub = await sugar.auto_breakeven(ticket, trigger_pips=40, plus_pips=1)
```

## `close_by_breakeven(ticket, plus_pips=0.0)`

```python
async def close_by_breakeven(ticket: int, plus_pips: float = 0.0)
```

A one-shot: close the order if it's at (or above) breakeven + `plus_pips` right now — useful
to lock in a scratch/small win on demand.

```python
await sugar.close_by_breakeven(ticket, plus_pips=1)
```
