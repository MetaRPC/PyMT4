# MT4Sugar — Order Entry

> One-line order entry with **pips-based SL/TP**, automatic normalization and defaults.

All entry methods return the new **ticket** (`int`). `lots` and the SL/TP arguments are
keyword-only. Use `sl_pips`/`tp_pips` for pip distances **or** `sl_price`/`tp_price` for
absolute prices. Omitted `symbol`/`magic`/`deviation_pips` fall back to
[defaults](./1.%20Connection_Defaults.md).

---

## Market orders

```python
async def buy_market(symbol=None, *, lots=None, sl_pips=None, tp_pips=None,
                     sl_price=None, tp_price=None, comment=None, magic=None, deviation_pips=None) -> int
async def sell_market(**kwargs) -> int   # same arguments
```

```python
# simplest
ticket = await sugar.buy_market("EURUSD", lots=0.01)

# with pip-based SL/TP and a tag
ticket = await sugar.sell_market("EURUSD", lots=0.01, sl_pips=20, tp_pips=40, magic=777)
```

---

## Pending orders

```python
async def buy_limit(symbol=None, *, price, lots=None, sl_pips=None, tp_pips=None,
                    sl_price=None, tp_price=None, comment=None, magic=None) -> int
async def sell_limit(**kwargs) -> int
async def buy_stop(**kwargs) -> int
async def sell_stop(**kwargs) -> int
```

`price` (the pending entry) is required.

```python
ask = (await sugar.last_quote("EURUSD"))["ask"]
# buy the dip 30 pips below, with pip-based protection
ticket = await sugar.buy_limit("EURUSD", price=ask - 0.0030, lots=0.01, sl_pips=15, tp_pips=30)

# breakout stop above, absolute SL/TP
ticket = await sugar.buy_stop("EURUSD", price=ask + 0.0020, lots=0.01,
                              sl_price=1.0950, tp_price=1.1080)
```

---

## `place_order(...)` — the unified entry

```python
async def place_order(side: str, order_type: str, symbol=None, price=None, lots=None,
                      sl_pips=None, tp_pips=None, sl_price=None, tp_price=None,
                      comment=None, magic=None, deviation_pips=None) -> int
```

The method all the helpers above delegate to. `side` is `"buy"`/`"sell"`, `order_type` is
`"market"`/`"limit"`/`"stop"`. Handy when the side/type are computed at runtime.

```python
side = "buy" if signal_up else "sell"
ticket = await sugar.place_order(side=side, order_type="market", symbol="EURUSD",
                                 lots=0.01, sl_pips=20, tp_pips=40)
```
