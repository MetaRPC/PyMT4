# MT4Sugar — Order Info & Exposure

> Query open orders and summarize exposure, with simple filters.

---

## `find_orders(symbol=None, magic=None, side=None, state=None, min_profit=None)`

```python
async def find_orders(symbol=None, magic=None, side=None, state=None, min_profit=None) -> list[dict]
```

Search orders by filters, returned as a list of dicts. `side` is `"buy"`/`"sell"`,
`state` is `"open"`/`"pending"`/`"closed"`, `min_profit` keeps only orders at/above a profit.

```python
mine   = await sugar.find_orders(magic=777)
buys   = await sugar.find_orders(symbol="EURUSD", side="buy", state="open")
winners = await sugar.find_orders(min_profit=0.0)
for o in mine:
    print(o)
```

## `orders_for_symbol(symbol)`

```python
async def orders_for_symbol(symbol: str) -> list
```

All current orders on one symbol (shortcut for `find_orders(symbol=...)`).

```python
orders = await sugar.orders_for_symbol("EURUSD")
print(len(orders), "order(s) on EURUSD")
```

---

## `positions_value(symbol=None, magic=None)`

```python
async def positions_value(symbol: str | None = None, magic: int | None = None) -> float
```

Aggregate value / floating P/L of matching open positions.

```python
pnl = await sugar.positions_value(symbol="EURUSD")
print(f"EURUSD floating: {pnl:+.2f}")
```

## `exposure_summary(by_symbol=True)`

```python
async def exposure_summary(by_symbol: bool = True) -> dict
```

A summary of net exposure — per symbol (`by_symbol=True`) or overall. Handy for a risk
dashboard line.

```python
summary = await sugar.exposure_summary(by_symbol=True)
print(summary)
```
